# Smart Retail Analytics & Demand Forecasting

A beginner-friendly portfolio project using Python, scikit-learn, FastAPI, and Streamlit.

## Features
- Linear Regression: estimate sales quantity.
- Decision Tree: predict purchase likelihood.
- K-Means: group customers using spending and purchase frequency.
- DBSCAN: flag unusual transactions.
- FastAPI: expose model predictions as endpoints.
- Streamlit: provide a simple interactive dashboard.

> This project generates synthetic example data. Predictions are educational demos, not business-grade forecasts. Replace the generated data with clean, real historical data before drawing business conclusions.

## Requirements
- Python 3.10 or newer
- VS Code
- Python extension for VS Code

## Setup (Windows PowerShell)
Open this folder in VS Code. In Terminal > New Terminal, run:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python generate_data.py
python train_models.py
```

If PowerShell blocks activation, run this in the current terminal:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```
Or use Command Prompt and run `.venv\Scripts\activate.bat`.

## Run the API
Keep the virtual environment activated and run:
```powershell
uvicorn app.main:app --reload
```
Open:
- API home: http://127.0.0.1:8000/
- Interactive API docs: http://127.0.0.1:8000/docs

Use the `/docs` page to try each POST endpoint. Example `/forecast` body:
```json
{
  "price": 30,
  "discount": 0.1,
  "advertising_spend": 100,
  "previous_sales": 50
}
```

## Run the dashboard
Open a **second terminal** in VS Code, activate the same `.venv`, then run:
```powershell
streamlit run dashboard.py
```
The browser dashboard will open. Keep the API terminal running.

## Troubleshooting
- `py` is not recognized: install Python from python.org and enable "Add Python to PATH".
- `ModuleNotFoundError`: activate `.venv` and run `pip install -r requirements.txt`.
- Model file missing: run `python generate_data.py`, then `python train_models.py`.
- Dashboard cannot connect: make sure the API is running at `http://127.0.0.1:8000`.
- Port 8000 is busy: use `uvicorn app.main:app --reload --port 8001` and update the dashboard URL.
